\# Student Management System



A console-based Java application to manage student records, courses, marks, 

attendance, and report cards — built with Core Java, JDBC, and MySQL.



\## Features



\- \*\*Student Management\*\* — Add, view, search, update, and delete students

\- \*\*Course Management\*\* — Manage courses with duration, semesters, and fees

\- \*\*Marks Management\*\* — Enter marks per subject and semester with auto grade calculation

\- \*\*Attendance Tracking\*\* — Mark daily attendance, calculate percentage, and check exam eligibility (≥ 75%)

\- \*\*Report Card Generation\*\* — Per-semester and overall percentage, grade, and result status

\- \*\*Rank List\*\* — Rank all students by overall percentage

\- \*\*Export\*\* — Export marksheet to a text file

\- \*\*Validation\*\* — Input validation for email, phone, dates, and marks

\- \*\*Layered Architecture\*\* — Model → DAO → Service → UI
